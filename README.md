# OTT Subscriber Retention Analysis

Identifying OTT subscribers at high risk of churn using SQL and Python, and turning the findings into actionable retention strategies.

## 🎯 Business Question

> Which subscribers are most likely to churn, and what factors are associated with higher churn risk?

## 🛠️ Tech Stack

- **Languages:** Python, SQL
- **Libraries:** NumPy, Pandas, Matplotlib, Seaborn
- **Database:** SQLite

## 🔄 Workflow

Raw Data → Cleaning → Feature Engineering → SQL Analysis → EDA & Visualisation → Business Insights

## 📊 What I Analysed

- Churn by subscription tier
- Impact of support escalations on churn
- Tenure vs. retention
- High-risk customer segments

## 🧮 Engineered Features

Customer tenure, support interaction frequency, escalation indicators, and customer risk indicators.
